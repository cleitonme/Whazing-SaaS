# Erp Provedor

Integrações para **provedores de internet e ERPs de telecomunicação** direto no atendimento do WhatsApp:

* 📄 **2ª via de boletos** — o cliente informa o CPF/CNPJ e recebe os boletos em aberto;
* 🔓 **Desbloqueio de confiança** — desbloqueia o acesso do assinante automaticamente;
* 🎫 **Abertura de chamados** — cria chamados técnicos na plataforma sem atendente humano.

> ⚠️ Todas as integrações desta seção **exigem o CPF ou CNPJ do cliente** antes de executar. Ao ativar, o sistema cria automaticamente um bot de identificação que coleta esses dados.
