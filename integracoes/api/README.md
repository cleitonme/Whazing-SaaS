# API

A API do Whazing permite que outros sistemas conversem com o seu atendimento — por exemplo, enviar mensagens, consultar contatos, criar tickets e acessar templates.

> 💡 **O que é API?** É um "endereço" que permite a troca de informações entre sistemas. Veja o [Glossário](../../glossario.md) para uma explicação simples.
