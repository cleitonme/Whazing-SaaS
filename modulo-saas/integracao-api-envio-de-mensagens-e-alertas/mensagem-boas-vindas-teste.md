# Mensagem de boas-vindas teste

### Como Configurar Mensagem de Boas-Vindas de Teste

Siga estes passos simples para configurar uma mensagem de boas-vindas:

### Passo 1: Acessar as Notificações WhatsApp

1. Acesse **Painel SaaS → Comunicação → Notificações WhatsApp**

### Passo 2: Configurar URL e Token da API

1. Preencha o campo **URL DA API** com a URL da API que receberá os envios
2. Preencha o campo **Token** com o token da API

<figure><img src="../../.gitbook/assets/image (65).png" alt=""><figcaption></figcaption></figure>

### Passo 3: Habilitar o envio da mensagem de boas-vindas

1. Habilite a opção **"Habilitar envio WhatsApp enviar solicitar teste"**
2. Será enviado um WhatsApp de **boas-vindas** quando um novo teste for solicitado

#### Mensagem padrão

```
🌟 Bem-vindo(a) à plataforma Whatsapp! 🌟

Se precisar de ajuda para configurar, não hesite em enviar uma mensagem para o suporte. Estamos prontos para fornecer todo o auxílio necessário! 😊

🕒 Aproveite seu teste de 3 dias!

www.seusite.com.br
```

Use as seguintes variáveis para personalizar a mensagem:

```bash
{{nomeempresa}}
```

```bash
{{nomeresponsavel}}
```

```bash
{{email}}
```

```bash
{{senha}}
```
