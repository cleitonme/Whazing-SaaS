# Envio WhatsApp aviso fatura em aberto

Siga estes passos simples para configurar o envio de aviso de fatura em aberto:

#### Passo 1: Acessar as Notificações WhatsApp

1. Acesse **Painel SaaS → Comunicação → Notificações WhatsApp**

#### Passo 2: Configurar URL e Token da API

1. Preencha o campo **URL DA API** com a URL da API que receberá os envios
2. Preencha o campo **Token** com o token da API

#### Passo 3: Habilitar o aviso de fatura em aberto

1. Habilite a opção **"Habilitar envio WhatsApp aviso fatura em aberto"**

Será enviado um WhatsApp **7 dias, 3 dias, 1 dia e no dia do vencimento** da fatura em aberto.

#### Mensagem padrão

```
💰 Aviso Importante — Fatura Disponível! 💰

Olá! 👋 Sua fatura já está disponível para pagamento diretamente na opção *Financeiro* do sistema.
Acesse sua conta e confira os detalhes.

👉 www.seusite.com.br

Se precisar de qualquer ajuda, nossa equipe de suporte está à disposição! 😊
```

Suporta variáveis para personalizar a mensagem.
