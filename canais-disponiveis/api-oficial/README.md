# Api Oficial

Para conectar a API Oficial via Whazing existem 3 métodos: **direto** (App próprio), **Hub MultiAPIWA** e **Hub NotificaMe**.

> 🚫 O **Hub MultiAPIWA** é **exclusivo do Whazing** — não funciona em outros sistemas.

🔀 **Quer a conexão mais simples, direto dentro do Whazing, sem o cliente copiar token nem configurar webhook?** Conheça o [Hub MultiAPIWA (conexão integrada)](hub-multiapiwa.md) — atende **WhatsApp Oficial, Instagram e Facebook**.

⚙️ **É administrador do SaaS?** Veja [Ativar e vender o Hub MultiAPIWA](hub-multiapiwa-ativacao.md).

Para quem quiser manter aplicativo e usar coexistência único método suporta isso via HUB

> 🔀 Quer usar a API Oficial e a Não Oficial do mesmo número juntas? Conheça o [Modo Híbrido](../modo-hibrido.md).

## 💰 Economizando mensagens da API Oficial

Cada mensagem enviada pela API Oficial tem custo pela Meta. O Whazing oferece recursos para **reduzir esse consumo sem trocar de API**:

* [**Concatenador de Mensagens**](concatenador-de-mensagens.md) — junta as mensagens enviadas em sequência pelo atendente em uma só;
* [**Chat externo por link**](chat-externo-por-link.md) — o cliente continua a conversa por uma página web parecida com o WhatsApp, sem mensagem oficial;
* [**Franquia mensal grátis**](franquia-mensal-gratis.md) — entenda as mensagens grátis que cada número recebe por mês e como acompanhar o uso.
