# Automação

Tudo o que o sistema pode fazer **sozinho** para você: responder, organizar, disparar e agendar.

> 💡 **Nunca usou o sistema?** Veja [Primeiros Passos](../../primeiros-passos.md) e o [Glossário](../../glossario.md).
>
> 🧭 **Regra de bolso:** *Chatbot* atende o cliente seguindo um menu; *Regras de automação* reagem a palavras e horários; *Campanhas* fazem disparos; *Agendamentos* publicam ou enviam na hora marcada.
