# Contatos

A tela de **Contatos** reúne todos os clientes que já conversaram com a sua empresa pelo sistema. A partir dela você pode:

* Ver o histórico de conversas e mídias de cada contato;
* Cadastrar contatos manualmente ou **importar em massa** por arquivo CSV;
* Acessar os arquivos enviados e recebidos em cada conversa.

> 💡 **Dica:** use as **etiquetas** para classificar os contatos (ex.: VIP, Pendente) e as **carteiras** para direcionar cada contato a um responsável.

## 📄 Páginas desta seção

* [Importar Contatos](importarcontatos.md) — cadastre vários contatos de uma vez usando um arquivo CSV
* [Arquivos do Contato](arquivos-do-contato.md) — veja as mídias e arquivos de cada conversa
* [Histórico de Mídias por Contato](historico-de-midias-por-contato.md) — consulte o histórico de mídias de um contato específico
