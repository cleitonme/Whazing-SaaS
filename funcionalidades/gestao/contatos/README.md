# Contatos

A tela de **Contatos** reúne todos os clientes que já conversaram com a sua empresa pelo sistema — e também os que foram cadastrados ou importados manualmente. A partir dela você pode:

* Buscar e filtrar contatos por nome, número, etiqueta, carteira, canal e informações adicionais;
* Ver o histórico de conversas e mídias de cada contato;
* Cadastrar contatos manualmente ou **importar em massa** por arquivo CSV — inclusive contatos **somente com e-mail**, sem telefone;
* Acessar os arquivos enviados e recebidos em cada conversa.

> 💡 **Dica:** use as **etiquetas** para classificar os contatos (ex.: VIP, Pendente) e as **carteiras** para direcionar cada contato a um responsável.
